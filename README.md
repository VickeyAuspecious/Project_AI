
# Project AI

## Overview
This project aims to create an AI assistant that uses the Ollama LLM installed locally. The goal is to develop a hands-free assistant similar to Copilot for Windows.

## Features
- **Local LLM Integration**: Utilize the Ollama LLM for natural language processing.
- **Hands-Free Operation**: Enable voice commands and responses for a seamless user experience.
- **Interactive Assistant**: Provide real-time feedback and assistance based on user input.

## Installation
1. Install the Ollama LLM locally.
2. Clone this repository.
3. Follow the setup instructions in the `SETUP.md` file.

## Usage
- Launch the AI assistant application.
- Use voice commands to interact with the assistant.
- The assistant will respond and perform tasks based on your input.
